drive-rag privacy policy

Last updated: September 25, 2026

drive-rag is a personal tool used only by its owner. It is not offered to anyone else.

What it accesses

With the owner's consent, drive-rag uses the Google Drive read-only scope (https://www.googleapis.com/auth/drive.readonly) to read the owner's own files. It cannot create, modify, share, or delete anything in Google Drive.

How data is used and stored

  • File text is split into passages and stored in a search index on the owner's own computer.
  • To make the index searchable by meaning, passages are sent to an embedding service (Voyage AI) that converts them into numeric vectors. No other third party receives Google user data.
  • When the owner asks a question, the most relevant passages are shown to the owner's own AI assistant to answer it.
  • Google user data is not sold, shared for advertising, or used for any purpose other than the owner's personal search.

Retention and deletion

The index lives only on the owner's computer and can be deleted at any time. Access can be revoked at myaccount.google.com/permissions.

Google API Services User Data Policy

drive-rag's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
